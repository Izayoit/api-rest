# Mi Primer API REST con Spring Boot

Este proyecto es una API RESTful desarrollada con **Spring Boot** y **MySQL** para la gestión de productos, categorías y facturación.

## Tecnologías utilizadas
* Java 17+
* Spring Boot
* MySQL Workbench
* Maven

## Base de Datos
La estructura de la base de datos se encuentra en la carpeta `/sql`. 
Para usarla:
1. Crea un esquema en MySQL llamado `springbot`.
2. Ejecuta el archivo `bd_backup.sql` para generar las tablas.

## Cómo ejecutar
1. Clona el repositorio.
2. Configura tu usuario y contraseña de MySQL en `src/main/resources/application.properties`.
3. Ejecuta la aplicación desde IntelliJ IDEA.
